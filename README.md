# Value Graph

Code and content for Venkat's personal website, showcasing work on **Valuable**, an AI layer on top of the **Value Graph**.

## What's here (planned)

- **Intro article**: the LinkedIn article "What does 'customer value' actually mean?", used as the home page.
- **Interactive demo**: explore the Value Graph using fictional ACME Corp (accounts payable) data. Ask preset questions, trace answers back to their sources, and switch between the Value view and the Portfolio (skills) view.

## How content grows

Each new article is a release of the graph. Graph data ships as static snapshot files exported per release, so the site needs no live backend. All data is fictional or anonymized.

Next planned article: "How are we doing against our KPIs?"
